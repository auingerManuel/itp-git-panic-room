# #1 - Branch Strategie

## Name

+ Wie heißt der Hauptbranch?
Lösung: main
+ Wie heißen Feature-Branches?
Lösung: Das Feature genau das du hinzüfügen möchtest
+ Wie erkennt man, woran gearbeitet wird?
Lösung: an den Namen des Branch

## Arbeit

+ Darf direkt auf main gearbeitet werden?
Lösung: Grundlegende Änderungen ja, Features nein
+ Wann wird ein neuer Branch erstellt?
Lösung: Für jeden neuen Bereich
+ Wann wird ein Branch gelöscht?
Lösung: Wenn der Bereich erfolgreich fertig ist


# #2 - Commit & Merge

## Regeln

### Commit
+ Commit auf deutsch und in Stichwürter

+ Commits beschreiben was du hinzu / verändert / gelöscht hast

+ Im Team nachfragen ob sich jeder unter dem Commit was vorstellen kann

### Merge

+ Über einen Merge kommt der Code in das main
+ ja wir würden das per pull machen
+ Wir haben uns alle merge rechte gegeben das wir nicht vom Leiter abhänig sind
