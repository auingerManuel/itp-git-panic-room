# Commot Master

Commit Messages helfen dabei:

+ Änderungen schnell zu verstehen
+ Fehler leichter zu finden
+ im Team den Überblick zu behalten

❌ Schlechte Commit Messages machen Projekte unübersichtlich. ✅ Gute Commit Messages sparen Zeit und Nerven.

## Analyse

### Gut
+ Add login validation
+ Refactor Calculator for readability
+ Remove unused imports
+ final version
+ Improve performance
+ Update Calculator
+ Handle edge cases
+ Add null check
+ Cleanup
+ Improve readability
+ Fix issue #23

### Böse
+ stuff
+ Changes in app
+ Small fixes
+ Rename variables
+ Adjust logic
+ Refactor code
+ Temporary fix
+ Update
+ Fix bug


## 3 Begriffe erklären

+ stuff, ist bei Böse weil es gibt keine Aussagen über eine Änderung oder irgendeiner Arbeit

+ final version, gibt das Ende des Projekts / Bereichs an Signalisiert die Gruppenmitglieder ohne Absprache nicht dort zu arbeiten.

+ Fix Bug ist zu ungenau und gibt keine Infos welcher genau gelößt wird, könnte man mit einer Nummerierung 



## Verbessern

+ Cleanup, ist für mich ok weil es ist eine Allgemeine Info jedoch würd ich genau Mittelen in welcher Datei gearbeitet wurde

+ Fix issue #23, mann sollte nur kurz Erwähnen was genau geändert wurde

+ Improve readability, ist wieder sehr allgemein, sollte mehr genauer angegeben was mei Lesbar gemacht wird.

+ Remove unused imports, angeben welche Imports gelöscht werden weil vielleicht arbeitet wer gerade in einem anderen Branch und benutzt diesen Import
